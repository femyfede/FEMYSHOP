# FEMYSHOP

A Django-based online shop project focused on selling products and managing an e-commerce store.

## Overview
This project was created to demonstrate a simple shop interface with product-related functionality and a Django backend.

## Tech Stack
- Python
- Django
- SQLite

## Run locally
1. Create a virtual environment.
2. Install dependencies.
3. Run:

```bash
python manage.py migrate
python manage.py runserver
```

## Purpose
This repository is a practical example of a small e-commerce application built with Django.
